## 第二轮：主修样式

先是位置。

啊我现在知道当时为什么一直在底部了。应该是css样式问题。
{% highlight ruby %}
  .toc {
  position: fixed;
  top: 100px;
  right: 20px;
  }
{% endhighlight %}
通过调整top/bottom, right/left，就可以调整toc作为sidebar相对于页面的位置
